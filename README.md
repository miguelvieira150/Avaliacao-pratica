Placar de Futebol

Site simples para acompanhar resultados de jogos de futebol, placares ao vivo e tabelas de classificação.

Funcionalidades

Visualização de placares ao vivo e jogos encerrados

Filtro de partidas por data e campeonato

Tabela de classificação atualizada

Layout adaptado para celular e computador

Tecnologias

HTML

CSS

JavaScript

API de dados de futebol

Como executar

Baixe ou clone este repositório.

Abra a pasta do projeto.

Adicione sua chave da API no arquivo de configuração.

Abra o arquivo index.html no seu navegador.
